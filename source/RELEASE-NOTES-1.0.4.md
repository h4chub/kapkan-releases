# KapKan 1.0.4 Public Beta

Fixes Fabric missing-library errors when launching separate or custom mods folders. KapKan keeps installation metadata and libraries in the shared cache, validates the exact selected profile and repairs missing/damaged Fabric JARs before Minecraft starts. Existing worlds, mods, accounts and settings stay in place.

Install over the existing app while KapKan and Minecraft are closed. Mac supports the existing Apple Silicon/Intel target; Windows supports the existing x64 target.

Validated with all 31 built-in release IDs plus three snapshot fixtures and real Fabric cache preflight for 26.1, 26.1.2 and 1.21.11. Native Mac/Windows installation and real Minecraft gameplay were not run for this exact build. Packages remain unsigned. Companion support remains Minecraft 26.1.2/Fabric.
