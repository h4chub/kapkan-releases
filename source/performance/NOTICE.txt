The selected upstream version explicitly lists Minecraft 26.1, 26.1.1 and
26.1.2 for Fabric in its official Modrinth metadata. KapKan limits auto-loading
to those exact targets, Java 25 and Fabric Loader 0.19.5+. It does not infer support
for other game versions from a broad dependency declaration.

Default behavior and recovery:
- The launcher adds verified bundled JAR paths to its per-process fabric.addMods
  argument. It does not copy into or replace any user mods folder.
- Existing direct/nested/provided mod IDs win, including modified replacements.
  Known conflicts and reverse breaks/conflicts suppress the corresponding mod.
  If an active mod cannot be inspected safely, the entire addition is skipped.
- In Settings, turn off "Use rendering optimizations" for graphics-mod
  compatibility. Changes apply the next time Minecraft starts. Alternatively set
  enabled=false in ~/.kapkan/performance.properties, or use the diagnostic
  system property -Dkapkan.performance.disabled=true, to disable bundled mods for
  the next game process. You may provide your own compatible/modified versions in
  your normal mods folder instead; KapKan preserves them. Upstream licenses permit
  the modifications, debugging and replacement described by their own terms.
- No render distance, visual quality, frame limit, JVM memory or other game option
  is changed by this integration. Upstream mods retain their own normal settings.

Sodium is not included. The inspected official candidates embed PolyForm Shield
1.0.0 with noncompete terms, so redistribution was not assumed for this client.
